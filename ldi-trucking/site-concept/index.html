Automation behind this

Quote requests reach dispatch in seconds

The form posts to a webhook that logs the request (Excel/SharePoint list or the TMS), emails the shipper a confirmation with a reference #, and alerts dispatch in Teams with a suggested rate pulled from LDI's own history on that lane. Quotes with no reply get an automatic follow-up after 24 hours; won/lost feeds the management dashboard.

Webhook → n8n / Power AutomateTeams alertLane history in SQL/Excel
Automation behind this

Self-serve PODs and an always-current carrier packet

When a driver photographs the signed BOL/POD, an AI document reader extracts the load #, consignee, signature and any exception notes, files it under the load, and makes it downloadable here. "Can you send me the POD?" emails stop, and billing gets the same file instantly.

Insurance expirations are tracked, so the carrier packet and COI regenerate automatically when a policy renews.

Automation behind this

Speed-to-lead for driver applicants

Drivers apply to several carriers the same day, and the first one to call usually wins. On submit, the applicant gets an instant text and email, lands in the recruiting tracker with a basic qualification check (CDL class, experience, endorsements) and their nearest yard, and that yard's recruiter gets a "call now" alert. Unfinished applications get automatic text nudges on day 1, 3 and 7.

SMS + emailRecruiting tracker / CRMRouting by yard
Automation behind this

Paperless onboarding

The follow-up link collects the CDL, medical card and signed consent forms from the driver's phone. OCR reads the expiration dates straight off the documents and starts the driver qualification (DQ) file checklist automatically, with no retyping. Missing items trigger reminders to the driver, not to the recruiter's to-do list.

Paperwork that files itself

Every upload is read by AI. A BOL/POD is attached to the load and its invoice packet; lumper and scale receipts are matched to the load as billable accessorials; a renewed medical card updates the compliance tracker with the new expiration date. Missing signatures or unreadable photos trigger a text back to the driver before they leave the dock.

90-day plan

Weeks 1–2

Discover + quick win

  • On-site days shadowing Recruiting, Safety, Dispatch and Billing
  • Map current systems: TMS, ELD, Microsoft 365, accounting
  • Rank tasks by hours spent and error risk
  • Ship the expiration tracker
Weeks 3–6

Documents + applicants

  • BOL/POD → invoice packet pipeline with human review
  • Applicant speed-to-lead and follow-up sequence
  • Mobile onboarding document collection
Weeks 7–12

Connect + report

  • Integrations between TMS, accounting and Microsoft 365
  • Management dashboard by yard
  • Inbox triage; internal assistant if the need is real
Ongoing

Run it properly

  • Every automation documented: what it does, who owns it, how to switch it off
  • Run logs and failure alerts
  • Short training per department

How remote work would run

  • 30-minute weekly meeting on Teams or Zoom: demo what shipped, agree on next week's priority
  • On-site when it matters: discovery days at the start, and training when something goes live
  • Shared project board so every department sees what's in progress
  • Async questions by Teams or email between meetings

Security guardrails

  • Driver and employee data stays in LDI-controlled accounts (Microsoft 365 / LDI cloud)
  • Least-privilege access, removable on day one
  • Business-tier AI APIs that don't train on LDI data; no driver data in consumer chat tools
  • Audit logs on every automated action; a person approves anything non-routine
